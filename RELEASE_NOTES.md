# Nian Vision 0.1.0

This release establishes the validated M8 Linux distribution path.

- Linux x86_64 AppImage built against the Debian 12 glibc baseline.
- Application-owned FFmpeg 8.0.3 shared runtime with GPL/nonfree disabled.
- Signed Tauri v2 updater artifact and release-time public/private key verification.
- Worker and desktop AppImage runtime smoke coverage, including headless desktop startup.
- Versioned release metadata, provenance, third-party notices and SHA-256 checksums.

Forgejo remains the authoritative source repository and normal CI platform.
GitHub is a one-way mirror used only for hosted release CI and public binary distribution.
